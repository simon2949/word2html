# LessonScene 场景协议草案

协议版本：0.1  
状态：设计草案

## 1. 目的

LessonScene 是受信任模板实例化结果、交互运行时、保存和 HTML 导出之间的稳定边界。

模型只负责生成紧凑 LessonPlan，包括模板选择、参数覆盖、安全通用函数规格、受限时间实验规格或不支持原因；受信任的本地模板/运行时负责实例化 LessonScene，渲染器再将其转换成可交互页面。模型不直接生成 LessonScene，更不生成需要执行的 HTML、CSS 或 JavaScript。

## 2. 设计原则

1. **声明式**：描述“有什么”和“如何关联”，不携带任意程序代码。
2. **可验证**：所有字段、范围、引用和表达式都能在渲染前验证。
3. **可复用**：固定结构放在模板中，具体数值和样式放在实例中。
4. **可迁移**：协议、模板和渲染器独立版本化。
5. **可追踪**：记录场景来源、模板来源和补丁历史。
6. **确定性**：相同协议、模板、参数和运行时版本应得到相同结果。

## 3. 四层模型

### 3.1 Template

模板保存可复用结构：对象、参数定义、依赖关系、交互方式、不变量和默认外观。

模板不保存某个用户的编辑状态。模板必须有稳定标识和不可变版本号，例如 `math.conic.ellipse-focus-sum@1`。

### 3.2 Scene Instance

场景实例引用模板，并保存本次内容的：

- 参数值；
- 标题和说明文字；
- 对模板对象的允许覆盖；
- 新增或隐藏的可选对象；
- 来源及修改记录。

### 3.3 Appearance

外观层保存颜色、线宽、字号、显示开关、动画速度和布局。外观变化不应改变学科计算结果。

### 3.4 Runtime State

运行状态保存当前拖动位置、播放状态、缩放比例等瞬时数据。默认不写入模板；只有用户明确保存时才写入场景实例。

## 4. 顶层结构

LessonScene 至少包含以下部分：

| 字段 | 用途 |
|---|---|
| `schemaVersion` | 场景协议版本 |
| `id` | 场景实例唯一标识 |
| `templateRef` | 模板标识与版本 |
| `metadata` | 名称、学科、知识点、年级范围、语言 |
| `viewport` | 画布范围、比例、缩放限制 |
| `parameters` | 用户可修改的输入参数 |
| `derivedValues` | 由参数或交互状态推导的数值 |
| `objects` | 需要渲染的图形对象 |
| `controls` | 面板中展示的滑块、输入框和开关 |
| `interactions` | 拖动、播放、暂停、重置等行为 |
| `annotations` | 标题、说明、公式、数值标签 |
| `invariants` | 场景必须满足的学科规律 |
| `appearance` | 显示样式和可见性配置 |
| `lineage` | 生成、复用和修改来源 |

顶层字段以外的未知字段默认拒绝，避免模型把不可控内容塞入场景。

## 5. 参数定义

每个参数需要声明：

- 稳定 ID；
- 用户可见名称；
- 数值、布尔、枚举或文本类型；
- 默认值；
- 最小值、最大值和步长；
- 单位及显示格式；
- 是否允许用户修改；
- 与其他参数之间的约束；
- 术语说明，例如“长轴全长”与“半长轴”。

参数 ID 一旦发布不得在同一模板主版本中改变语义。

## 6. 派生值与表达式

派生值由安全表达式描述。运行时解析表达式并建立依赖图。

限制如下：

- 禁止 `eval`、函数构造器和动态模块加载；
- 只允许数字、参数引用、运行状态引用和白名单运算符；
- 白名单函数初期包括基本代数、三角函数、绝对值、最小值和最大值；
- 引用必须指向已声明的参数、状态或派生值；
- 依赖图必须无环；
- 除显示舍入外，内部计算保留足够精度；
- 除法、开方和反三角函数必须检查定义域。

## 7. 场景对象

MVP 数学渲染器先支持：

- 坐标轴；
- 网格；
- 点和约束点；
- 线段、直线和向量；
- 圆和椭圆；
- 参数曲线或函数曲线；
- 文本、公式和数值标签；
- 轨迹。

每个对象需要稳定 ID、对象类型、几何输入、外观引用、可见条件和可选的交互能力。

对象只能通过 ID 引用其他对象。缺失引用、重复 ID 或类型不兼容均应在渲染前报错。

## 8. 控件与交互

MVP 控件支持：

- 数值输入；
- 滑块；
- 布尔开关；
- 枚举选择；
- 播放、暂停和重置按钮。

MVP 交互支持：

- 参数更新；
- 对象显示切换；
- 约束点拖动；
- 沿闭合曲线自动运动；
- 视口缩放和复位；
- 恢复参数及外观默认值。

时间实验运行状态额外包含 `t`、播放状态和轨迹采样。模型只能提供持续时间、`x(t)`、`y(t)`、测量表达式，以及从质点出发的速度/加速度等矢量分量和显示比例；所有表达式仍由同一白名单解析器执行，单次持续时间限制在 0.2–60 秒。矢量的颜色、箭头形状和长度上限由本地渲染器控制，模型不能提供 SVG 或样式代码。

交互事件只能触发协议内置动作，不能携带任意脚本。

## 9. 外观模型

外观配置由设计令牌和对象覆盖组成。初期允许：

- 语义颜色，例如主图形、重点对象、辅助线和警告；
- 允许列表中的颜色值；
- 线宽、虚实线、透明度；
- 点大小和标签字号；
- 坐标轴、网格、标签、测量值和轨迹可见性；
- 动画速度；
- 明亮或深色背景主题。

协议不接受选择器、样式表文本或 HTML 事件属性。

## 10. 不变量与验证

每个模板可以声明一个或多个不变量：

- 条件名称和教学含义；
- 需要计算的表达式；
- 期望值或合法范围；
- 数值容差；
- 失败时的用户提示；
- 是阻止发布还是仅显示警告。

验证按顺序执行：

1. JSON Schema 结构验证；
2. ID、引用和类型验证；
3. 参数范围和跨参数约束验证；
4. 表达式安全及依赖环验证；
5. 学科规则和不变量验证；
6. 渲染器能力验证；
7. 导出安全检查。

## 11. 修改补丁

当前统一工作台不使用左侧自然语言入口修改参数或显示效果，这些修改由右侧设置控件直接产生受约束补丁。补丁只允许：

- 修改参数值；
- 修改允许的外观字段；
- 修改标题和说明文字；
- 切换可选对象；
- 调整现有交互的允许参数。

删除必需对象、修改表达式或改变模板结构属于模板开发行为，需要经过代码审查和完整场景验证，不能由线上模型直接修改。自然语言入口只负责创建教学内容，并在模板直接复用与大模型规划之间路由。

每次补丁保存原场景版本、修改来源、修改时间和影响字段，保证可以作为一个整体撤销。

## 12. 复用与指纹

场景检索指纹由以下信息组成：

- 学科和知识点；
- 交互模式；
- 场景对象类型集合；
- 参数定义签名；
- 教学不变量；
- 协议和模板版本；
- 语言。

复用优先级为：

1. 已保存场景的精确指纹；
2. 相同模板、不同参数；
3. 相同知识点和交互模式的相似场景；
4. 由已有组件组合的新场景。

模板升级后，旧缓存不能静默复用到新版本；必须重新验证或完成显式迁移。

## 13. 椭圆模板映射

椭圆模板的核心定义如下：

| 类型 | 内容 |
|---|---|
| 输入参数 | 长轴全长、短轴全长、动点初始角度 |
| 派生值 | 半长轴、半短轴、焦距、两个焦点坐标 |
| 图形对象 | 椭圆、两个焦点、约束点、两条距离线 |
| 测量值 | 点到两个焦点的距离及其和 |
| 交互 | 拖动、自动运动、播放、暂停、重置 |
| 不变量 | 两段距离之和等于长轴全长 |
| 显示项 | 坐标轴、网格、标签、距离、公式、轨迹 |

详细行为和边界条件见 `ellipse-mvp-acceptance.md`。

## 14. 版本规则

- 修复说明文字或增加可选字段：小版本升级；
- 改变字段语义、表达式行为或对象模型：主版本升级；
- 每个主版本提供明确迁移器；
- 导入时先读取协议版本，再决定验证、迁移或拒绝；
- 导出 HTML 固定其使用的运行时版本，避免未来升级改变行为。
