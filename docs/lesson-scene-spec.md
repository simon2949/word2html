# LessonScene 场景协议草案

协议版本：0.1  
状态：设计草案

## 1. 目的

LessonScene 是受信任模板实例化结果、交互运行时、保存和 HTML 导出之间的稳定边界。

模型只负责生成紧凑 LessonPlan，包括模板选择、参数覆盖、安全通用函数、二维关系曲线、数据图表、二维几何、二维圆盘碰撞、受限时间实验规格或不支持原因；受信任的本地模板/运行时负责实例化 LessonScene，渲染器再将其转换成可交互页面。模型不直接生成 LessonScene，更不生成需要执行的 HTML、CSS 或 JavaScript。

## 2. 设计原则

1. **声明式**：描述“有什么”和“如何关联”，不携带任意程序代码。
2. **可验证**：所有字段、范围、引用和表达式都能在渲染前验证。
3. **可复用**：固定结构放在模板中，具体数值和样式放在实例中。
4. **可迁移**：协议、模板和渲染器独立版本化。
5. **可追踪**：记录场景来源、模板来源和补丁历史。
6. **确定性**：相同协议、模板、参数和运行时版本应得到相同结果。

## 3. 四层模型

### 3.1 Template

模板保存可复用结构：对象、参数定义、依赖关系、交互方式、不变量和默认外观。

模板不保存某个用户的编辑状态。模板必须有稳定标识和不可变版本号，例如 `math.conic.ellipse-focus-sum@1`。

### 3.2 Scene Instance

场景实例引用模板，并保存本次内容的：

- 参数值；
- 标题和说明文字；
- 对模板对象的允许覆盖；
- 新增或隐藏的可选对象；
- 来源及修改记录。

### 3.3 Appearance

外观层保存颜色、线宽、字号、显示开关、动画速度和布局。外观变化不应改变学科计算结果。

### 3.4 Runtime State

运行状态保存当前拖动位置、播放状态、缩放比例等瞬时数据。默认不写入模板；只有用户明确保存时才写入场景实例。

## 4. 顶层结构

LessonScene 至少包含以下部分：

| 字段 | 用途 |
|---|---|
| `schemaVersion` | 场景协议版本 |
| `id` | 场景实例唯一标识 |
| `templateRef` | 模板标识与版本 |
| `metadata` | 名称、学科、知识点、年级范围、语言 |
| `viewport` | 画布范围、比例、缩放限制 |
| `parameters` | 用户可修改的输入参数 |
| `derivedValues` | 由参数或交互状态推导的数值 |
| `objects` | 需要渲染的图形对象 |
| `controls` | 面板中展示的滑块、输入框和开关 |
| `interactions` | 拖动、播放、暂停、重置等行为 |
| `annotations` | 标题、说明、公式、数值标签 |
| `invariants` | 场景必须满足的学科规律 |
| `appearance` | 显示样式和可见性配置 |
| `lineage` | 生成、复用和修改来源 |

顶层字段以外的未知字段默认拒绝，避免模型把不可控内容塞入场景。

### 4.1 点线外观

`appearance` 使用有限枚举表达点线样式，不接受任意 CSS：

- `lineWidth` 与 `lineStyle` 控制函数曲线、实验轨迹等主图线；`lineStyle` 可为 `solid`、`dashed` 或 `dash-dot`；
- `helperLineWidth` 与 `helperLineStyle` 独立控制焦点连线、对称轴、矢量和约束等辅助线；
- `pointRadius` 与 `pointStyle` 控制重点对象大小和样式；`pointStyle` 可为 `solid`、`outlined` 或 `shadow`；
- 这些样式字段保持可选，以兼容未声明它们的 LessonScene 0.1 文件。运行时缺少字段时采用模板默认样式。

### 4.2 对象级外观覆盖

`appearance.objectStyles` 是可选的对象 ID 到外观补丁的映射。对象 ID 必须引用 `objects` 中真实且支持外观编辑的对象；网格、坐标轴等由场景统一控制的对象不能伪装成可编辑对象。

允许字段按对象类型收窄：

| 对象类型 | 允许字段 |
|---|---|
| 点、时间实验物体 | `color`、`pointRadius`、`pointStyle`、`visible` |
| 曲线、线段、射线、圆弧、多边形、轨迹、矢量、约束、地面线 | `color`、`lineWidth`、`lineStyle`、`visible` |
| 标签 | `color`、`fontScale`、`visible` |

解析优先级为“对象覆盖 → 对象角色默认 → 场景默认 → 模板默认”。颜色只能使用六位十六进制值，线型和点样式只能使用协议枚举，数值继续服从 Schema 范围；不接受 CSS、选择器、HTML 或脚本。空映射和整个字段均可省略，因此旧场景无需迁移即可继续使用。

工作台中的“显示效果”编辑场景默认值，“对象”编辑 `objectStyles[objectId]`。修改前者只影响仍在继承默认值的对象，不能删除后者；清除某个对象的补丁后，该对象立即重新继承整体值。两层设置必须在界面中使用“整体显示/对象细调”和“继承/局部覆盖”状态明确区分。

`selectedObjectId` 只属于工作台运行时状态，不是 LessonScene 字段。完整 LessonScene、自动草稿和独立 HTML 保留 `objectStyles`；紧凑 LessonPlan 场景包仍丢弃所有纯外观覆盖，以减少文件和模型上下文。

### 4.3 样式与布局预设

样式预设不是新的任意样式语言。运行时把稳定预设 ID 展开成现有 `theme`、颜色、线宽、线型、点大小、点样式和字号字段，再按普通 LessonScene 外观校验。当前预设为 `teaching-clean`、`focus-emphasis`、`projected-high-contrast`、`dark-presentation` 和 `print-friendly`；预设 ID 不写入协议，场景只保存展开后的确定性结果。

`appearance.layoutPreset` 是可选枚举：

| 值 | 独立 HTML 行为 |
|---|---|
| `centered` | 图像居中，隐藏测量卡与参数区 |
| `with-metrics` | 显示图像和测量卡，隐藏参数区 |
| `with-parameters` | 显示图像、测量卡与参数区 |
| `compact` | 保留完整控制，但缩小间距与控制区 |

旧场景缺少该字段时等价于 `with-parameters`。布局字段不能作为对象的 `visibleWhen` 条件。工作台预览和独立 HTML 使用同一枚举；完整 LessonScene 和草稿保留它，紧凑 LessonPlan 与其他纯外观一起丢弃。

## 5. 参数定义

每个参数需要声明：

- 稳定 ID；
- 用户可见名称；
- 数值、布尔、枚举或文本类型；
- 默认值；
- 最小值、最大值和步长；
- 单位及显示格式；
- 是否允许用户修改；
- 与其他参数之间的约束；
- 术语说明，例如“长轴全长”与“半长轴”。

参数 ID 一旦发布不得在同一模板主版本中改变语义。

## 6. 派生值与表达式

派生值由安全表达式描述。运行时解析表达式并建立依赖图。

限制如下：

- 禁止 `eval`、函数构造器和动态模块加载；
- 只允许数字、参数引用、运行状态引用和白名单运算符；
- 白名单函数初期包括基本代数、三角函数、绝对值、最小值和最大值；
- 引用必须指向已声明的参数、状态或派生值；
- 依赖图必须无环；
- 除显示舍入外，内部计算保留足够精度；
- 除法、开方和反三角函数必须检查定义域。

## 7. 场景对象

MVP 数学渲染器先支持：

- 坐标轴；
- 网格；
- 点和约束点；
- 线段、直线和向量；
- 圆和椭圆；
- 参数曲线或函数曲线；
- 文本、公式和数值标签；
- 轨迹。

时间实验还支持声明式 `constraint` 对象：`constraintType` 为 `rope` 或 `spring`，`anchorId` 引用受约束的运动物体，三个安全表达式分别描述固定点横坐标、纵坐标和自然长度。绳约束会在整个采样区间校验“物体到固定点的距离等于绳长”；弹簧允许长度变化，显示自然长度与当前长度。两者都不包含或执行模型代码。

二维几何模板 `math.geometry.primitives-2d` 使用 `point`、`locus`、`segment`、`ray`、`vector`、`arc`、`polygon` 和 `label` 对象。点必须且只能使用坐标表达式，或使用中点、平移、旋转、轴对称、位似、垂足之一构造；构造依赖图无环。只有坐标点可拖动，并可约束到圆、直线或线段，鼠标输入会在本地投影回约束对象。轨迹对象只引用目标点与驱动参数，运行时固定采样 241 点，不接受模型生成的点列或路径。紧凑 `geometrySpec` 以未加场景前缀的 ID 建立引用；实例化后对象获得稳定场景 ID。距离测量引用两点，角度测量引用三点且第二点为顶点，面积测量按边界顺序引用至少三点。

二维关系曲线模板 `math.curve.relation-2d` 使用单个 `relation-curve` 对象。紧凑 `relationSpec` 的三种模式互斥：参数方程只允许 `t`，极坐标只允许 `theta`，隐函数零等值线只允许 `x`、`y` 与已声明参数。视口、参数区间和参数范围均在本地验证；固定运行时生成采样点或等值线片段，模型和导入文件不能提供点列、路径、采样密度或执行代码。参数修改会重新采样且不调用模型。

数据图表模板 `math.data.chart-2d` 使用 `data-chart`、`chart-axis`、`data-category` 和一种系列对象。紧凑 `dataChartSpec` 的 `table`、`bar`、`line` 共用 1–24 个类别，所有系列的 `values` 必须与类别等长；`scatter` 不包含类别，每个系列只包含 1–60 个数值点。场景最多 4 个系列，所有值为绝对值不超过 `1e9` 的有限数。固定运行时生成语义表格或 SVG 坐标轴、图例和图形标记；模型和导入文件不能提交 SVG、路径、绘图库配置或执行代码。系列对象可独立调整颜色、线型、线宽、点大小、点样式和显示状态，具体字段随系列类型收窄。

二维接触模板 `physics.collision.discs-2d` 使用一个 `contact-surface` 和 2–8 个 `collision-body` 对象。紧凑 `collisionSpec` 只声明矩形边界、持续时间、二维重力、0–1 恢复系数，以及每个圆盘的初始位置、速度、半径和质量；所有数值来自参数与安全表达式。本地运行时以固定 240 Hz 时间步、稳定 ID 顺序和固定接触迭代次数生成轨迹，校验器会预演完整时段。协议不接受模型生成的逐帧位置、碰撞回调或求解代码。

每个对象需要稳定 ID、对象类型、几何输入、外观引用、可见条件和可选的交互能力。同一模板版本内，渲染器的 SVG/Canvas 元素必须使用该稳定 ID 暴露选择映射，不能用数组位置代替持久对象身份。

对象只能通过 ID 引用其他对象。缺失引用、重复 ID 或类型不兼容均应在渲染前报错。

## 8. 控件与交互

MVP 控件支持：

- 数值输入；
- 滑块；
- 布尔开关；
- 枚举选择；
- 播放、暂停和重置按钮。

MVP 交互支持：

- 参数更新；
- 对象显示切换；
- 约束点拖动；
- 沿闭合曲线自动运动；
- 视口缩放和复位；
- 恢复参数及外观默认值。
- 选择可编辑对象、修改对象允许的外观字段、隐藏/恢复对象和恢复单个对象默认值。

二维关系曲线支持参数更新、缩放、适应窗口、重置和曲线对象样式编辑；它不包含时间播放。需要动点、轨迹播放或焦点距离连线时继续使用数学模式的 `experiment.motion.point-2d`。

数据图表支持缩放、适应窗口、坐标轴/网格/数据值标签切换、重置和系列对象样式编辑；数据表模式使用可滚动语义表格，缩放用于调整表格显示比例。数据值和类别属于教学结构，需通过结构化二次编辑修改，不作为右侧外观参数。

时间实验运行状态额外包含 `t`、播放状态和轨迹采样。模型只能提供持续时间、最多 4 个质点的 `x(t)`/`y(t)`、测量表达式，以及从指定质点出发的速度/加速度/动量等矢量分量和显示比例；所有表达式仍由同一白名单解析器执行，单次持续时间限制在 0.2–60 秒。测量量 ID 可以作为派生变量复用，运行时按依赖顺序计算并拒绝循环。矢量的颜色、箭头形状和长度上限由本地渲染器控制，模型不能提供 SVG 或样式代码。

二维碰撞运行状态包含 `t`、圆盘位置与速度、累计接触次数、总动能和二维总动量。参数变化会在浏览器本地重新计算并再次校验完整时段，不调用模型；重置恢复场景包中的默认初始条件。总动量或总动能是否守恒取决于外力、边界冲量和恢复系数，不能把条件性规律写成所有参数下恒成立。

交互事件只能触发协议内置动作，不能携带任意脚本。

## 9. 外观模型

外观配置由设计令牌和对象覆盖组成。初期允许：

- 语义颜色，例如主图形、重点对象、辅助线和警告；
- 允许列表中的颜色值；
- 线宽、虚实线、透明度；
- 点大小和标签字号；
- 坐标轴、网格、标签、测量值和轨迹可见性；
- 动画速度；
- 明亮或深色背景主题。

对象覆盖必须经过对象引用和对象类型校验。点不能接受线宽或线型，线不能接受点半径或点样式，标签不能接受点线字段；`visible` 只影响该对象，不替代场景级坐标轴、网格和辅助内容开关。

协议不接受选择器、样式表文本或 HTML 事件属性。

## 10. 不变量与验证

每个模板可以声明一个或多个不变量：

- 条件名称和教学含义；
- 需要计算的表达式；
- 期望值或合法范围；
- 数值容差；
- 失败时的用户提示；
- 是阻止发布还是仅显示警告。

验证按顺序执行：

1. JSON Schema 结构验证；
2. ID、引用和类型验证；
3. 参数范围和跨参数约束验证；
4. 表达式安全及依赖环验证；
5. 学科规则和不变量验证；
6. 渲染器能力验证；
7. 导出安全检查。

## 11. 修改补丁

当前统一工作台不使用左侧自然语言入口修改参数或显示效果，这些修改由右侧设置控件直接产生受约束补丁。补丁只允许：

- 修改参数值；
- 修改允许的外观字段；
- 修改标题和说明文字；
- 切换可选对象；
- 调整现有交互的允许参数。

删除必需对象、修改表达式或改变模板结构属于模板开发行为，需要经过代码审查和完整场景验证，不能由线上模型直接修改。自然语言入口只负责创建教学内容，并在模板直接复用与大模型规划之间路由。

每次补丁保存原场景版本、修改来源、修改时间和影响字段，保证可以作为一个整体撤销。

## 12. 复用与指纹

场景检索指纹由以下信息组成：

- 学科和知识点；
- 交互模式；
- 场景对象类型集合；
- 参数定义签名；
- 教学不变量；
- 协议和模板版本；
- 语言。

复用优先级为：

1. 已保存场景的精确指纹；
2. 相同模板、不同参数；
3. 相同知识点和交互模式的相似场景；
4. 由已有组件组合的新场景。

模板升级后，旧缓存不能静默复用到新版本；必须重新验证或完成显式迁移。

## 13. 椭圆模板映射

椭圆模板的核心定义如下：

| 类型 | 内容 |
|---|---|
| 输入参数 | 长轴全长、短轴全长、动点初始角度 |
| 派生值 | 半长轴、半短轴、焦距、两个焦点坐标 |
| 图形对象 | 椭圆、两个焦点、约束点、两条距离线 |
| 测量值 | 点到两个焦点的距离及其和 |
| 交互 | 拖动、自动运动、播放、暂停、重置 |
| 不变量 | 两段距离之和等于长轴全长 |
| 显示项 | 坐标轴、网格、标签、距离、公式、轨迹 |

详细行为和边界条件见 `ellipse-mvp-acceptance.md`。

## 14. 版本规则

- 修复说明文字或增加可选字段：小版本升级；
- 改变字段语义、表达式行为或对象模型：主版本升级；
- 每个主版本提供明确迁移器；
- 导入时先读取协议版本，再决定验证、迁移或拒绝；
- 导出 HTML 固定其使用的运行时版本，避免未来升级改变行为。
