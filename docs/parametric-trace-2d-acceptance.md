## 1. 验收目标

确认数学参数轨迹不是一个只存在于第三方测试包中的特殊案例，而是能够从官方库直接复用、在固定运行时中播放和修改，并以独立 HTML 保持相同教学语义的正式代表能力。

代表场景用受限表达式参数化双曲线左右两支，并显示两个固定焦点、右支动点到两个焦点的两条距离线，以及距离差绝对值和理论常量 `2a`。模型不提供轨迹点列、SVG 路径或执行代码。

## 2. 自动验收

- 官方库包含 `official.hyperbola-focus-difference`，且每次读取返回不可变克隆；
- “双曲线任一点到两焦点距离差绝对值不变”请求直接复用官方场景，模型调用为 0；
- 场景通过 LessonScene、表达式、资源上限、渲染器和独立 HTML 导出检查；
- 在完整时间区间抽样时，左右两支均满足 `||PF1|-|PF2|| = 2a`；
- 改变 `a`、`b`、轨迹范围和描绘时间后仍由本地运行时重新计算。
- 数学参数轨迹只允许拖动真正随参数变化的物体，固定焦点保持不可拖动；
- 动点可按 `0.1`、`0.5` 或 `1` 单位把最终 `x` 或 `y` 坐标吸附到对应网格线；运行时求取附近轨迹与网格线的交点，并选择最接近拖动目标的合法时刻；多物体共享同一时刻并同步更新；
- 管理员预览和独立 HTML 使用相同的拖点、吸附及固定点识别语义。

## 3. 真实浏览器验收

先运行 `npm run dev`，然后执行：

```bash
npm run acceptance:parametric-trace -- 9333 http://127.0.0.1:5173
```

若 `9333` 已有 Chrome 调试页面，脚本复用该页面；若端口未启动，脚本会自动创建一个隔离的无界面 Chrome，并在验收后关闭和清理。地址参数也兼容 Markdown 链接文本，但建议始终使用上面的纯 URL。

脚本断言：

1. 公式说明位于完整的 `900 × 590` 参数轨迹画布上方；
2. 双曲线左右两支动点和两个焦点均显示；
3. 右支动点通过两条无箭头直线连接两个焦点，并标注实时长度；
4. 默认 `a=3` 时距离差为 6，改为 `a=4` 后立即变为 8；
5. 播放后左右两支同步形成轨迹，暂停有效；
6. 单独选择一条焦点距离线并改为虚线，只产生对象级本地样式覆盖；
7. 放大和适应窗口控制可用；
8. 草稿保留参数及对象样式，独立 HTML 包含完整运行时且没有网络依赖。
9. 右支动点可拖动，固定焦点不可拖动；步长为 `1` 时，拖动后的动点 `x` 或 `y` 必须为整数，左右两支同步到同一轨迹时刻且距离差仍为 `2a`；
10. 独立 HTML 包含同样的轨迹—网格线求交、最终点坐标吸附和可拖动物体识别运行时。

## 4. 学科人工复核重点

- `c = sqrt(a^2+b^2)` 与双曲线标准方程的约定一致；
- 左、右支参数化分别覆盖对应分支，不能把参数区间误解为完整实数范围证明；
- 两条显示线确实从同一个动点连接到 `F1`、`F2`，标签数值与欧氏距离一致；
- 结论明确为距离差的绝对值等于 `2a`，不混写为距离和；
- 调节 `a`、`b` 后焦点、图形和理论常量同步变化；
- 数值演示用于帮助理解定义，不替代解析证明。
