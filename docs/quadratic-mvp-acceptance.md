# 二次函数顶点变化：验收标准

文档版本：0.2

更新日期：2026-08-27

关联模板：`math.function.quadratic-vertex@1`

状态：自动测试、真实浏览器验收与既有学科审核均已通过。

## 1. 教学目标

用户能够通过顶点式 `y = a(x − h)² + k` 调整 `a、h、k`，直观看到抛物线的开口方向、宽窄、顶点和对称轴变化。

## 2. 默认场景

- `a = 1、h = 0、k = 0`；
- 顶点为 `(0, 0)`，对称轴为 `x = 0`，开口向上；
- 默认显示公式、坐标轴、正方形网格、顶点、顶点标签和对称轴；
- 公式说明位于函数图像上方；
- 视口完整显示顶点和主要曲线，并支持 50%～160% 缩放。

## 3. 必需验收项

### AC-Q01 模板路由与复用

- 包含“二次函数/抛物线”和“顶点/开口/对称轴/图像变化”的请求直接命中本地模板，模型 token 为 0；
- 能抽取 `a、h、k` 或“顶点为 `(h, k)`”中的初始值；
- 相同规范化描述再次生成时复用已校验缓存。

### AC-Q02 参数与数学正确性

- `a` 范围为 `[-3, 3]` 且不能为 0，`h` 范围为 `[-8, 8]`，`k` 范围为 `[-6, 6]`；
- 顶点始终为 `(h, k)`，对称轴始终为 `x = h`；
- `a > 0` 时开口向上，`a < 0` 时开口向下，`|a|` 增大时曲线变窄；
- 参数变化期间本地即时重算，不发送模型请求；
- 至少采样 100 组对称点验证 `f(h-d) = f(h+d)`。

### AC-Q03 显示与交互

- x、y 方向采用同一像素比例，网格单元保持正方形；
- 函数坐标画布占满圆角图像框，顶点和根等指标位于框外的独立信息栏；
- 坐标刻度随视口自动选择并避免明显重叠；
- 可以独立控制坐标轴、网格、对称轴、顶点标签和公式说明；
- 可以修改抛物线、顶点、对称轴颜色及曲线线宽；
- 参数改变后恢复适应窗口，顶点不能永久移出画面。

### AC-Q04 安全、保存与导出

- 场景通过 LessonScene Schema、表达式白名单、引用和二次函数不变量校验；
- 保存、撤销、重做和 JSON 导入导出支持二次函数场景；
- 独立 HTML 在离线状态下仍可修改 `a、h、k`、显示选项、颜色和缩放；
- 导出文件不包含 API Key、模型提示词或外部网络依赖。

### AC-Q05 模型规划补充

- 本地规则未明确命中但语义属于顶点式二次函数时，MiniMax 可以返回紧凑 LessonPlan 并选择本模板；
- 模型只能提供 `coefficientA、vertexH、vertexK`，不能修改公式、对象、交互代码或样式；
- 其他未安装内容返回 `unsupported`，并保留当前场景。

## 4. 完成定义

上述必需项、数学属性测试、独立 HTML 语法测试和生产构建全部通过，且现有椭圆模板无回归。
