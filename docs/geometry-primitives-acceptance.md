## 专项真实浏览器验收

执行命令：

```bash
npm run acceptance:geometry-primitives -- 9333 http://127.0.0.1:5173
```

应用本身需要先通过 `npm run dev` 运行。若未检测到 `9333` 调试端口，脚本会使用公共浏览器连接层自动启动隔离的无头 Chrome。

脚本包含以下确定性断言：

- 公式位于画布上方，画布铺满圆角框内容区，横纵网格像素间距一致；
- A、B、C 三个可拖点，线段、向量、射线、角弧、填充多边形和三种测量均完整显示；
- 默认 `AB=6`、`∠ABC≈68.199°`、面积 `15`；射线与向量有箭头，线段没有箭头；
- 参数取边界值时，全部顶点仍位于绘图区，SVG 属性不出现 `NaN` 或 `Infinity`；
- 重置、拖点、相关测量联动、撤销、重做、对象级多边形点划线、点大小与投影样式、缩放和草稿保存生效；当前锁定纵坐标的拖动用例检查角度变化，面积允许因三角形高度不变而保持不变；
- 三种测量标签的屏幕边界框互不重叠；按整数吸附并锁定纵坐标拖动时，横坐标为整数且纵坐标保持不变；
- 独立 HTML 包含固定几何原语、测量和拖动运行时，不含动态代码或网络依赖。

2026-08-27 已在隔离的无头 Chrome、`http://127.0.0.1:5181` 实际执行通过。记录确认默认 `AB=6`、`∠ABC=68.199°`、面积 `15`；参数极值下对象保持在绘图区且无非有限数据；拖点后面积更新为 `14.815`，撤销与重做恢复正确坐标；对象级多边形点划线、点投影与 `12 px` 大小、`100%→110%` 缩放、草稿和无网络依赖独立 HTML 均符合断言。
