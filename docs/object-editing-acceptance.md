# 对象级编辑验收

验收日期：2026-08-23

覆盖范围：椭圆、二次函数、通用函数和时间实验四类现有运行时。

## 1. 用户验收标准

1. 用户可以点击画布对象或对象列表选择可编辑对象，画布与列表同步高亮；
2. 选择对象后右侧自动打开“对象”标签，并只展示该类型允许修改的字段；
3. 修改左焦点、单条距离线或单个实验物体时，同类其他对象不发生变化；
4. 点支持颜色、3–18 px 大小、实心/轮廓/投影和显示状态；
5. 线支持颜色、1–10 px 线宽、实线/虚线/点划线和显示状态；
6. 标签支持颜色、0.8–1.5 倍字号和显示状态；
7. 当前对象可以恢复默认样式，修改支持撤销和重做；
8. 所有对象样式修改均在本地完成，模型调用次数和 token 使用量为 0；
9. 自动草稿、完整 LessonScene 和独立 HTML 保留对象覆盖，当前选择状态不持久化；
10. 紧凑 `.word2html.json` 继续丢弃纯外观，无效对象 ID、不可编辑对象和跨类型字段被拒绝。

## 2. 自动验证

基础回归：

```bash
npm test
npm run build
```

真实页面验收需要先启动应用，并打开一个带远程调试端口的 Chrome：

```bash
npm run acceptance:object-editor -- 9333 http://127.0.0.1:5181
```

脚本执行完整用户链路：选择左焦点，修改其颜色、大小和投影，确认右焦点不变，执行撤销/重做，隐藏/恢复对象，检查自动草稿，再把独立 HTML 放入隔离页面并核对同一外观结果。

## 3. 本次结果

- 左焦点对象 ID：`focusLeft`，右焦点保持原颜色与大小；
- 撤销移除局部投影，重做恢复局部投影；
- 隐藏和恢复只影响左焦点；
- 草稿保存 `appearance.objectStyles.focusLeft`，未保存 `selectedObjectId`；
- 独立 HTML 中左焦点颜色、半径和投影与工作台一致；
- 点线外观旧验收和绳/弹簧约束浏览器验收未发生回归。

结论：R1 首批对象选择与属性面板闭环通过。
