## 教学目标与边界

该运行时用于演示圆形物体在二维平面中的接触、反弹、动量交换、恢复系数和边界冲量。支持 2–8 个圆盘、矩形边界、恒定二维重力和 0–1 法向恢复系数。圆盘具有真实显示半径和质量。

当前不模拟摩擦、旋转、空气阻力、形变、持续接触堆叠、任意多边形刚体或三维运动；包含这些要求的描述应返回具体能力缺口，而不是降级成看似正确的圆盘实验。

## 自动验收

- 等质量、完全弹性正碰后速度交换，总动量和总动能在数值容差内保持；
- 圆盘与四条边界接触后始终处于合法范围；
- 参数修改与恢复默认全部在本地重算，模型调用为 0 token；
- A/B/C 的九个质量与二维初速度参数分别进入对应圆盘初始状态，互不串用；
- 初始重叠、过快状态和非白名单表达式被拒绝；
- 能力注册、LessonPlan 往返、MiniMax 收窄 Schema、官方库、独立 HTML 和 Skill 示例保持一致；
- 独立 HTML 不包含 `eval`、动态代码或外部依赖。
