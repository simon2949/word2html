# 当前场景包导出验收

## 目标

模型生成、文件导入、实验库打开或“修改当前”后的场景，都能被压缩成可分享的 `.word2html.json`，重新导入第三方库并继续二次编辑。导出过程不调用大模型。

## 验收项

1. 点击顶部“场景包”，下载文件名以 `.word2html.json` 结尾。
2. 文件信封为 `word2html.lesson-package` / `0.1`，API 版本为当前 `lesson-plan-1.4`。
3. 导出前修改过的公式、对象标签、运动表达式、矢量显示方式、约束和当前参数值在重新导入后保持一致。
4. 重新导入文件通过完整安全校验，自动进入本地第三方库，并可再次使用“修改当前”。
5. 紧凑包重新导入后采用运行时默认颜色与字号；如需保留纯显示外观，应改用“完整数据”。
6. “完整数据”和“导出 HTML”的既有行为不受影响。
7. 场景包导出不访问 MiniMax 接口，不消耗模型 token，也不包含 API 密钥。

## 自动验证

- `lessonPackage.test.ts` 覆盖 LessonScene → LessonPlan 包 → LessonScene 往返。
- 往返测试验证当前参数值、对象标签、距离连线模式和仅数值标签模式。
- `npm test` 与 `npm run build` 均通过。
