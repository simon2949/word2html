# 样式与布局预设验收

验收日期：2026-08-26

## 1. 验收范围

- 样式：教学简洁、重点突出、投影高对比、深色演示、打印友好；
- 布局：图像居中、图像加测量值、图像加参数区、紧凑控制；
- 运行时：椭圆、二次函数、通用函数、时间实验；
- 持久化：撤销/重做、自动草稿、完整 LessonScene、独立 HTML；
- 安全与成本：有限枚举、白名单外观补丁、零模型调用。

## 2. 自动验收

```bash
npm test
npm run build
node --check scripts/browser-preset-acceptance.mjs
```

自动测试覆盖：五种样式补丁、四种布局枚举、旧场景兼容、时间实验专用默认值、对象覆盖默认保留/明确清除、参数不被外观恢复重置、Schema 拒绝未知布局，以及独立 HTML 的深色画布和布局数据。

## 3. 真实浏览器验收

启动应用并打开带远程调试端口的 Chrome 页面后执行：

```bash
npm run acceptance:presets -- 9333 http://127.0.0.1:5173
```

脚本验证：

1. 页面展示 5 个样式预设和 4 个布局预设；
2. 选择“深色演示”只改变预览选择，点击应用后才修改场景；
3. 预先设置的左焦点局部颜色不被样式预设覆盖；
4. 撤销恢复浅色，重做恢复深色；
5. “图像居中”隐藏工作台测量卡；
6. 草稿保存深色主题、布局和对象覆盖；
7. 独立 HTML 使用深色画布、隐藏参数区和测量卡，并保留对象覆盖。
