# 复用优先生成与局部修改

版本：0.1  
更新日期：2026-08-24

## 1. 执行顺序

创建新场景按以下固定顺序执行：

1. 参数、显示效果或对象属性修改交给本地面板，模型调用为 0；
2. 椭圆和二次函数等审核模板直接实例化；
3. 查询绑定了描述、能力 ID、模型版本和协议版本的精确缓存；
4. 查询官方库和已审核第三方库；
5. 精确知识点或同能力场景直接复用，并在本地套用明确数值参数；
6. 相似场景压缩为 LessonPlan，作为同学科、同运行时的二次编辑基准；
7. 没有安全候选时才使用已注册运行时生成新规划；
8. 缺少本地原语时停止，不允许模型临时生成脚本或渲染器。

本地未审核的第三方条目不会参与自动复用。用户仍可从实验库手动打开、检查和修改这些条目。

## 2. 匹配级别

| 级别 | 判断依据 | 执行动作 | 模型调用 |
| --- | --- | --- | --- |
| 精确匹配 | 描述命中审核条目的标题、知识点或常用别名 | 直接加载 | 0 |
| 同能力复用 | 命中相同知识点和运行时，可只改变明确参数 | 本地复制并校验 | 0 |
| 相似场景 | 学科、运行时相同，文本和交互结构达到阈值 | 基于紧凑 LessonPlan 二次编辑 | 通常 1 |
| 需要新规划 | 没有安全候选 | 用已注册能力生成 | 通常 1 |

官方条目的复用提示保存在 `LessonLibraryEntry.reuseHints` 中，包括常用描述、核心概念词、辅助关键词和交互签名。共享第三方库只接收服务端标记为 `verified` 的条目；没有复用提示时仅使用经过规范化的标题、知识点和摘要匹配。

## 3. 能力指纹与缓存隔离

能力指纹不包含参数当前值，包含：

- 稳定能力 ID、模板 ID 和学科；
- 对象种类与角色；
- 交互触发与动作；
- 参数 ID 与类型。

因此同一正弦函数场景的 `A=2` 与 `A=3` 具有相同能力指纹，可以复用；正弦函数与自由落体的指纹不同，不能互相命中。

创建缓存键包含规范化描述、能力 ID、模型提供商/版本、LessonScene 协议和复用策略版本。二次编辑缓存另外包含基准 LessonPlan 的完整稳定哈希、模板和学科，防止同一句修改要求跨基准场景命中。

## 4. 模型输入收窄

命中已注册运行时后，浏览器向生成服务发送稳定能力 ID。服务端再次按允许列表验证该 ID，并把工具 Schema 收窄为固定的：

- `subject`；
- `templateId`；
- `matched` 状态；
- `functionSpec` 或 `experimentSpec` 之一；
- 空 `parameterOverrides`。

系统提示只包含当前能力需要的表达式、数量和交互限制。相似场景和“修改当前”继续使用基准 LessonPlan 生成的模板限定 Schema。浏览器收到结果后再次检查学科和运行时是否与能力 ID 一致。

这不能保证模型服务商实际计费一定减少固定比例，但可以确定减少发送给模型的无关说明和可选字段，并降低输出漂移后触发第二次纠错调用的概率。

## 5. 当前可直接复用内容

- 椭圆焦点距离和；
- 二次函数顶点式；
- 正弦函数振幅和频率；
- 自由落体；
- 两个独立单摆。

例如“绘制 `y=A*sin(B*x)，A=3，B=2`”会复用官方正弦场景并在浏览器本地设置 `A`、`B`，不调用模型。“绘制 `y=A*cos(B*x)`”可把正弦场景作为通用函数运行时的相似基准，再由模型只修改收窄规划。

## 6. 自动检查

`src/core/sceneReuse.test.ts` 覆盖：

- 官方内容精确复用和零模型调用判断；
- 参数本地套用与范围校验；
- 相似场景只能作为模型编辑基准；
- 未审核第三方条目不得自动复用；
- 能力指纹跨参数稳定；
- 缓存按能力和基准计划隔离；
- 复用来源和预计调用节省能够在界面中读取。

`server/minimax.test.mjs` 另行检查首次生成工具 Schema 和系统提示已按能力收窄。
