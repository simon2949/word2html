# 椭圆焦点距离和：MVP 验收标准

文档版本：0.1  
关联模板：`math.conic.ellipse-focus-sum@1`

## 1. 验收目标

用户可以通过自然语言生成一个椭圆交互场景，修改长轴、短轴和显示效果，拖动椭圆上的点，并直观看到该点到两个焦点的距离之和保持为长轴全长。

## 2. 默认场景

- 长轴全长：10；
- 短轴全长：6；
- 半长轴：5；
- 半短轴：3；
- 焦距：4；
- 椭圆中心：坐标原点；
- 焦点：`(-4, 0)` 和 `(4, 0)`；
- 动点：位于椭圆右上区域；
- 距离显示：保留两位小数；
- 默认显示坐标轴、网格、焦点、辅助线、距离值和距离和；
- 默认不自动播放。
- 公式说明位于交互图像上方；
- 默认视图为“适应窗口”，完整显示椭圆和坐标系。

界面统一使用“长轴全长”和“短轴全长”。公式说明区域可以补充其与半长轴 `a`、半短轴 `b` 的关系。

## 3. 必需验收项

### AC-01 自然语言生成

给定包含“椭圆、焦点、距离之和、长短轴可调”含义的中文请求：

- 系统命中椭圆模板；
- 生成可操作预览；
- 不生成或执行任意 JavaScript；
- 将“核心”等明显上下文用词识别为“焦点”，同时在解析结果中提示术语规范化；
- 未提供数值时使用默认值；
- 提供数值时优先使用用户数值。

### AC-02 参数修改

- 修改长轴全长后，椭圆、焦点、距离和及视口同步更新；
- 修改短轴全长后，椭圆、焦点和辅助线同步更新；
- 参数修改期间不发送模型请求；
- 支持滑块和直接数值输入；
- 恢复默认值后回到默认场景。

### AC-03 参数约束

- 长轴全长和短轴全长必须大于零；
- 长轴全长必须大于或等于短轴全长；
- 输入非法时保留最后一个合法场景，并显示具体错误；
- 两者相等时允许显示圆，并提示“此时焦点重合，图形是椭圆的特殊情况”；
- 极小或极大合法值应自动调整视口，不能让图形完全不可见。

### AC-04 拖动行为

- 动点能够被鼠标和触摸拖动；
- 动点始终约束在椭圆上；
- 两条距离线实时连接动点和两个焦点；
- 距离值及距离和在拖动中实时变化；
- 快速拖动不会将点留在曲线外；
- 拖动结束后不变量校验仍然通过。

### AC-05 数学正确性

- 焦距按半长轴和半短轴计算；
- 焦点坐标与椭圆方向一致；
- 距离使用欧氏距离；
- 任意合法动点上，两段距离之和在数值容差内等于长轴全长；
- 内部计算精度高于界面显示精度；
- 显示舍入不能被用于判断不变量是否成立。

自动化测试至少采样椭圆上的 100 个位置。建议相对容差不大于 `1e-8`，并针对接近圆和高离心率场景单独测试。

### AC-06 显示效果

用户可以独立控制：

- 坐标轴；
- 网格；
- 焦点标签；
- 动点标签；
- 两条距离辅助线；
- 单段距离；
- 距离和；
- 公式说明；
- 运动轨迹。

用户可以修改主图形、焦点、动点和辅助线颜色，以及线宽、点大小和动画速度。所有修改应立即生效且不调用模型。

- x、y 方向必须使用相同的单位像素比例，网格单元为正方形；
- x、y 轴显示与当前视口匹配的坐标值，例如 `1、2、3` 或 `5、10、15`；
- 刻度过密时自动增大间隔，标签不能明显重叠；
- 焦点、动点等对象标签应避开坐标刻度标签；
- 支持 50%～160% 缩放和一键适应窗口；
- 椭圆坐标画布占满圆角图像框，距离指标位于框外的独立信息栏；
- 改变长短轴后自动恢复适应窗口，避免图形展示不完整。

### AC-07 动画

- 播放后动点沿椭圆连续运动；
- 暂停后保持当前位置；
- 再次播放从当前位置继续；
- 重置恢复初始位置和停止状态；
- 调整动画速度不改变数学结果；
- 页面不可见时不应继续进行高频无意义绘制。

### AC-08 生成请求路由

- 椭圆焦点距离和请求命中已有模板，不调用大模型；
- “隐藏网格”“把椭圆改成红色”“长轴改成 12”等设置请求不会生成场景，并提示使用右侧设置面板；
- 未匹配模板的教学内容标记为“需要大模型”；
- 模型生成端点未配置时保留当前场景并清楚提示；
- 端点已配置时，只有通过协议、安全、数学和渲染能力校验的返回值才能替换当前场景；
- 参数和显示控件产生的修改支持撤销和重做。

### AC-09 保存与恢复

- 刷新页面后可以恢复最近草稿；
- 保存内容包括参数、显示效果和可选的当前动点位置；
- 撤销与重做同时支持参数、显示和自然语言补丁；
- 另存为副本不会覆盖原场景。

### AC-10 导出与导入

- 能导出场景数据文件；
- 导入后恢复相同参数、外观和交互能力；
- 能导出可独立打开的 HTML；
- 导出的 HTML 不包含 API 密钥和内部提示词；
- 断开生成服务后，导出页面仍可修改参数、拖动、播放、暂停和重置；
- 导入损坏或不兼容文件时拒绝加载，并保留当前场景。

### AC-11 复用与 token

- 第一次同类请求可以进行模板选择和参数抽取；
- 第二次相同规范化请求可以直接命中缓存；
- 只改变长短轴时复用同一模板；
- 连续拖动和面板修改产生零模型 token；
- 日志记录模板 ID、命中级别、输入 token、缓存 token、输出 token 和总耗时；
- 模型失败不影响已经加载场景的本地编辑。

### AC-12 可访问性与适配

- 所有控件具有可读名称和当前值；
- 可以用键盘操作参数输入、开关、播放、暂停和重置；
- 焦点和动点除颜色外还有形状或文字区分；
- 系统启用“减少动态效果”时不自动播放；
- 桌面、平板和手机窄屏上均能完成参数修改和拖动；
- 缩放页面后关键控件不会被永久遮挡。

## 4. 边界测试矩阵

| 场景 | 输入 | 预期结果 |
|---|---|---|
| 标准椭圆 | 长轴 10，短轴 6 | 焦距 4，距离和 10 |
| 圆 | 长轴 10，短轴 10 | 焦点重合并显示特殊情况提示 |
| 高离心率 | 长轴 10，短轴接近允许下限 | 图形和距离仍稳定，无无效数值 |
| 非法轴长 | 长轴 6，短轴 10 | 拒绝应用并说明约束 |
| 零或负数 | 任一轴长不大于 0 | 拒绝应用并保留旧场景 |
| 非数字输入 | 输入空值或文本 | 显示输入错误，不破坏场景 |
| 快速连续输入 | 连续拖动滑块 | 不调用模型，画面保持响应 |
| 快速拖动 | 绕椭圆快速拖动动点 | 点保持在椭圆上，距离和正确 |
| 隐藏所有辅助项 | 关闭网格、标签、线段和数值 | 椭圆与动点仍可见且可操作 |
| 导出后离线打开 | 禁止网络后打开 HTML | 参数和交互功能正常 |

## 5. 自动化测试层级

- 协议测试：合法场景通过，非法字段、引用和表达式被拒绝；
- 数学属性测试：随机轴长和随机动点位置满足焦点距离和不变量；
- 组件测试：参数控件、开关、播放状态和错误提示；
- 端到端测试：输入文字、生成、修改、保存、刷新、导出和导入；
- 视觉回归测试：默认、圆、高离心率、窄屏和深色背景；
- 无障碍测试：自动扫描加键盘人工路径；
- 安全测试：脚本、事件属性和危险表达式不能进入运行时或导出文件。

## 6. 完成定义

椭圆 MVP 只有在以下条件同时满足时才算完成：

1. 所有 AC-01 至 AC-12 必需项通过；
2. 数学属性测试无失败；
3. 参数和显示修改不触发模型请求；
4. 相同需求能够证明模板复用和缓存生效；
5. 导出 HTML 完成离线验证；
6. 不存在执行模型生成脚本的路径；
7. 文档、场景协议和实际行为一致。
