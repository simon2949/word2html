# 多物体弹性碰撞 MVP 验收

关联运行时：`experiment.motion.point-2d@3`  
接口版本：`lesson-plan-0.4`

## 输入样例

> 演示两个小球的一维完全弹性碰撞，可调两个小球的质量和初速度，显示各自速度矢量、碰撞时刻和系统总动量。

## 必需结果

- 主物体和附加物体分别声明 `bodyId`、名称、`x(t)` 与 `y(t)`；
- 两个小球分别绘制、标注和保留独立轨迹；
- 速度或动量矢量通过 `bodyId` 绑定正确小球；
- `tc`、碰后速度等公共子表达式通过测量量 ID 复用，不重复展开；
- `step(t-tc)` 只用于安全的分段数值计算；
- 播放跨过碰撞时刻并继续展示碰后分离过程；
- 导出的单文件 HTML 在离线状态下保持相同行为；
- 参数或显示修改在本地完成，模型调用为 0 token；
- 相同自然语言描述命中已校验缓存后为 0 token。

## 安全边界

- 最多 4 个质点、6 个参数、4 个测量量、4 个矢量和 60 秒；
- 所有表达式使用同一白名单解析器，不执行 `eval` 或模型脚本；
- 派生量循环、未知物体锚点、除零、非有限或过大数值均拒绝应用；
- 当前只把质点视作几何点，不模拟接触半径、形变、摩擦或二维碰撞法线。

## 2026-08-19 验证结果

- 真实 MiniMax-M3 成功返回 `lesson-plan-0.4` 多物体计划：输入 2629、缓存输入 128、输出 1560 token；
- 服务端自动补足碰后观察窗口，参数/显示修改及相同描述缓存命中均为 0 token；
- Chrome 初始显示 2 个小球、球 1 的 `3.00 m/s` 速度矢量；
- 播放到 `2.74 s` 后显示 2 条独立轨迹和 2 个速度矢量，碰后速度分别为 `1.00 m/s`、`4.00 m/s`；
- 此时两个小球位置分别为 `1.74 m`、`3.96 m`，已经跨过 `tc=2.00 s` 并正确分离；
- 自动化回归共 69 项测试，生产构建通过。
