# 通用时间实验 MVP 验收

关联运行时：`experiment.motion.point-2d@2`

## 必需能力

- MiniMax 只返回持续时间、`x(t)`、`y(t)`、参数、测量量、可选矢量表达式与教学说明，不返回代码；
- 表达式仅允许 `t`、声明参数、基本运算和数学函数白名单；
- 支持 0.2–60 秒、最多 6 个参数、最多 4 个测量量和 4 个矢量；
- 播放、暂停、到达终点自动停止和重置均在浏览器本地完成；
- 参数变化后重新计算持续时间、视口和状态，并回到 `t=0`；
- 轨迹、运动对象、基准线、正方形网格和自适应刻度可正确显示；
- 速度、加速度等矢量从运动对象出发，箭头方向、长度变化、数值、单位和显示开关同步更新；
- 独立 HTML 无外部依赖，不包含 API Key，离线后仍可播放和调参；
- 相同规范化描述优先复用已校验缓存，参数修改为 0 token。

## 自由落体验收样例

- 输入：“模拟自由落体运动，可调初始高度和重力加速度，显示当前高度、速度、速度与重力加速度矢量和运动轨迹”；
- 运行时间：`sqrt(2*h0/g)`；
- 位置：`x=0`，`y=max(0,h0-0.5*g*t^2)`；
- `h0=20 m`、`g=9.8 m/s²` 时约 `2.02 s` 落地；
- 落地高度为 `0.00 m`，速度约为 `19.80 m/s`；
- 速度矢量为 `(0,-gt)`，重力加速度矢量为 `(0,-g)`，二者均指向下方；
- 浏览器播放期间物体位置、时间、高度、速度、矢量和轨迹同步更新。

## 当前验证

- 自动化测试覆盖安全表达式、位置与矢量状态计算、参数更新、重置、场景校验和离线导出；
- 真实 MiniMax-M3 规划通过 LessonPlan 0.3 和服务端语义校验，并返回速度、重力加速度两个矢量；
- 无头浏览器确认 `t=0` 时显示恒定重力加速度箭头，播放到 `1.43 s` 后同时显示 `14.04 m/s` 的速度箭头与 `9.80 m/s²` 的重力加速度箭头，矢量开关默认开启；
- 原有浏览器验收确认播放前后时间与物体位置均发生变化，并在落地时自动停止。
