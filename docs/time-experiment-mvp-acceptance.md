# 通用时间实验 MVP 验收

关联运行时：`experiment.motion.point-2d@4`

当前协议统一浏览器脚本与状态记录见 `motion-point-2d-acceptance.md`。

## 必需能力

- MiniMax 只返回持续时间、`x(t)`、`y(t)`、参数、测量量、可选矢量表达式与教学说明，不返回代码；
- 表达式仅允许 `t`、声明参数、基本运算和数学函数白名单；
- 支持 0.2–60 秒、最多 6 个参数、4 个运动物体、4 个测量量、4 个矢量和 4 个绳/弹簧约束；
- 测量量 ID 可以作为安全派生变量被位置、其他测量量和矢量复用，并拒绝循环依赖；
- 播放、暂停、到达终点自动停止和重置均在浏览器本地完成；
- 参数变化后重新计算持续时间、视口和状态，并回到 `t=0`；
- 轨迹、运动对象、基准线、正方形网格和自适应刻度可正确显示；
- 速度、加速度等矢量从运动对象出发，箭头方向、长度变化、数值、单位和显示开关同步更新；
- 绳或弹簧由固定点、受约束物体和自然长度表达式定义；绳长在整个运行区间校验恒定，弹簧长度允许变化；
- 独立 HTML 无外部依赖，不包含 API Key，离线后仍可播放和调参；
- 相同规范化描述优先复用已校验缓存，参数修改为 0 token。

## 多物体验收样例

- 两个质点分别拥有稳定 ID、位置表达式、标签、颜色和独立轨迹；
- 速度、动量等矢量通过 `bodyId` 绑定指定质点，不会错误地从主物体出发；
- 一维完全弹性碰撞可复用 `tc`、`v1`、`v2` 三个派生量，减少长公式重复和输出 token；
- 碰撞动画必须保留碰后观察窗口，不能在 `t=tc` 时立即停止；
- 参数组合导致除零或非有限结果时，拒绝该次修改并保留上一有效场景。

## 自由落体验收样例

- 输入：“模拟自由落体运动，可调初始高度和重力加速度，显示当前高度、速度、速度与重力加速度矢量和运动轨迹”；
- 运行时间：`sqrt(2*h0/g)`；
- 位置：`x=0`，`y=max(0,h0-0.5*g*t^2)`；
- `h0=20 m`、`g=9.8 m/s²` 时约 `2.02 s` 落地；
- 落地高度为 `0.00 m`，速度约为 `19.80 m/s`；
- 速度矢量为 `(0,-gt)`，重力加速度矢量为 `(0,-g)`，二者均指向下方；
- 浏览器播放期间物体位置、时间、高度、速度、矢量和轨迹同步更新。

## 约束验收样例

- 小角度单摆使用派生量 `theta=theta0*cos(sqrt(g/L)*t)`，位置为 `x=L*sin(theta)`、`y=-L*cos(theta)`，绳固定点为 `(0,0)`，自然长度为 `L`；
- 水平弹簧振子使用 `x=A*cos(w*t)`，弹簧固定点位于运动区间左侧，自然长度表示固定点到平衡位置的距离；
- 画布和独立 HTML 都绘制固定点、绳/弹簧、当前长度标签、物体与轨迹；
- 把长度变化的轨迹错误声明为 `rope` 时，场景在渲染前被拒绝。

## 当前验证

- 自动化测试覆盖安全表达式、位置、矢量与约束状态计算、恒定绳长验证、参数更新、重置、场景校验和离线导出；
- 真实 MiniMax-M3 规划通过 LessonPlan 0.3 和服务端语义校验，并返回速度、重力加速度两个矢量；
- 无头浏览器确认 `t=0` 时显示恒定重力加速度箭头，播放到 `1.43 s` 后同时显示 `14.04 m/s` 的速度箭头与 `9.80 m/s²` 的重力加速度箭头，矢量开关默认开启；
- 原有浏览器验收确认播放前后时间与物体位置均发生变化，并在落地时自动停止。
