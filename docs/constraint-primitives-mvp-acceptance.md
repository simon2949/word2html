# 绳与弹簧约束原语 MVP 验收

关联运行时：`experiment.motion.point-2d@4`  
接口版本：`lesson-plan-0.6`

## 目标

模型只描述受约束物体、固定点、自然长度和类型；浏览器使用审核过的原语完成计算、校验、绘制和交互，不执行模型返回的 HTML 或 JavaScript。

## 协议与安全

- `constraints` 最多 4 项，类型仅允许 `rope` 或 `spring`；
- 每项通过 `bodyId` 绑定已声明物体，缺失引用在渲染前拒绝；
- 固定点横纵坐标和自然长度均使用现有数学表达式白名单，可复用参数、时间和测量量；
- 自然长度必须为有限正数；
- `rope` 在 121 个运行区间采样点检查当前长度与自然长度，误差超过 `max(1e-6, L*1e-4)` 时拒绝场景；
- `spring` 允许当前长度变化，自然长度只表达平衡/自然状态；
- 当前接口升级为 `lesson-plan-0.6`，缓存键包含该版本，旧生成结果不会误命中新能力缓存。

## 显示与交互

- 绳显示为固定点到物体的直线，弹簧显示为沿两点方向生成的折线线圈；
- 两种约束都显示固定点标记、名称和当前长度；
- 约束与速度/动量等矢量共用“矢量与绳/弹簧约束”显示开关；
- 固定点参与自动视口估算，缩放后仍保持图像完整；
- 参数修改、播放、暂停、轨迹、重置均在本地运行；
- 独立 HTML 包含相同约束计算与绘图能力，无外部依赖。

## 验收场景

1. 小角度单摆：可调摆长 `L`、重力加速度 `g` 和初始摆角 `theta0`；摆球位置由 `theta` 派生量复用，绳长恒为 `L`。
2. 水平弹簧振子：可调振幅 `A` 和角频率 `w`；弹簧自然长度固定，当前长度随滑块运动变化，加速度矢量复用位移派生量。
3. 非法绳长：把水平振子弹簧改为绳后必须在实例化前报“未保持长度不变”。
4. 双钟摆：两个摆球分别绑定 `L1`、`L2` 和各自初始摆角，使用两个固定锚点与两条绳；修改任意一个摆长不影响另一个。

## 当前验证

- 自动化测试覆盖协议规范化、对象引用、单摆绳长、弹簧长度变化、SVG 渲染与独立 HTML 语法；
- 全量测试和生产构建通过；
- 真实 MiniMax-M3 一次成功返回 `lesson-plan-0.5` 单摆计划，包含摆球、摆绳、摆角、角频率、周期和实际绳长：输入 3022、缓存输入 128、输出 1129 token；
- 无头 Chrome 验收确认摆绳显示 `L=1.60 m` 且播放后摆球位置变化；弹簧显示为 27 点折线并显示当前长度 `7.00 m`；
- 全量 78 项测试和生产构建通过。

## 双钟摆生成修复

- 对表达式内容末尾意外多出的引号进行无歧义清理；
- 参数 ID 仅有大小写偏差时对齐到已声明 ID；
- 模型漏声明 `H1/H2` 时，只在对应绳与摆球纵坐标中将悬挂高度对齐到已知锚点或零点；高度平移不改变摆动规律和绳长，不会凭空添加参数；
- 其他未知标识符仍然拒绝，避免静默猜测物理量；
- 双钟摆提示使用固定锚点 `(-2,0)`、`(2,0)`，把 5 个参数额度用于共享 `g` 以及独立的 `L1`、`L2`、`theta01`、`theta02`；
- 使用原始输入完成真实 MiniMax-M3 验收：输入 3280、缓存输入 128、输出 1149 token，返回两摆球、两绳与五个独立/共享参数并通过规划校验。
- 无头 Chrome 确认同时显示 2 个摆球和 2 条绳；把 `L1` 从 `1.00 m` 调到 `2.20 m` 后，`L2` 保持 `1.50 m` 不变。
