# 数据表与统计图表验收

更新日期：2026-08-30  
范围：R5 数学第四批 `math.data.chart-2d` / `dataChartSpec`（`lesson-plan-1.4`）

## 已实现范围

- `table`：语义表格、标题、类别、1–4 个系列及单位；
- `bar`：正负值基线、分组柱形、图例和数值标签；
- `line`：多系列折线、数据点、图例和数值标签；
- `scatter`：多系列数值点、坐标标签和对象级点样式；
- 正方形网格、自适应坐标刻度、自动量程、缩放与适应窗口；
- 类别横轴使用独立的分布式类别比例尺：折线图首末类别铺满绘图区，柱状图按等宽槽位铺满；标签根据实际槽宽选择单行、双行或确定性抽样；
- 系列对象选择、显示状态、颜色、线型/线宽或点大小/点样式；
- 紧凑场景包导入导出、官方气温折线图、独立离线 HTML；
- MiniMax 首次生成和基于当前图表的结构化二次编辑；
- 管理员预览及有限数据/系列结构自动检查。

## 协议边界

- `table`、`bar`、`line` 必须包含 1–24 个不重复类别，各系列数值数量与类别一致；
- `line` 至少两个类别；
- `scatter` 不得包含类别，每系列包含 1–60 个 `{x,y}` 点；
- 每个场景 1–4 个系列，系列 ID 唯一，所有数值有限且绝对值不超过 `1e9`；
- 模型与导入文件不得提供 SVG、路径、绘图库配置、回调或执行代码；
- 当前不支持饼图、堆叠图、自动分箱直方图、箱线图、热力图、回归拟合和动态数据源。
