# 模型调用控制与费用熔断

文档版本：0.1

## 目标

这一层保护平台 API Key 与公共额度，但不改变 LessonPlan Schema、能力注册和安全运行时。官方模板、本地缓存、参数修改、样式修改和独立 HTML 运行均不经过模型控制器，也不消耗模型额度。

## 请求链路

浏览器为模型请求发送匿名设备 ID 与幂等键。游客使用临时自带 Key 时，服务端将匿名设备 ID 和网络来源摘要成不可逆客户端键；登录用户使用平台额度时，服务端将账号 ID 摘要成稳定且不对浏览器暴露的用量键。随后按操作范围执行：幂等检查 → 窗口限流 → 每日熔断 → 并发检查 → 模型调用 → token/费用记账。

操作范围包括 `generation`、`edit`、`correction`、`pre-review` 和 `connection-test`。共享场景提交本身另有独立限流；只有其中的 AI 预审占用模型额度。

## 幂等语义

- 同一客户端、同一操作范围、同一幂等键且请求内容一致：进行中的调用共享同一个 Promise，已完成调用在 TTL 内直接复用；
- 同一幂等键对应不同请求内容：返回 HTTP 409；
- 复用响应保留规划或预审结论，但用量返回 0，并标记 `deduplicated: true`；
- 调用失败不会缓存，允许用户修复网络或配置后重试；
- 管理员主动连接测试与 AI 预审重试使用唯一幂等键，确保动作真实执行。

## 熔断与响应

窗口限流、客户端额度和客户端并发返回 HTTP 429；平台全局并发或平台每日熔断返回 HTTP 503；响应包含稳定 `code`、中文 `error`、`retryAfterSeconds` 和 `Retry-After`。

费用是依据模型目录中的每百万 token 价格进行的估算，不是供应商账单。未配置价格时仍统计调用和 token，但费用保持 0，因此不应启用费用熔断。

用户临时自带 Key 的调用仍计入调用量和 token 防滥用上限，但费用由用户自己的供应商账户承担，因此其估算费用按 0 计入平台费用熔断。

## 管理与隐私

`GET /api/admin/model-usage` 需要管理员会话，只返回平台汇总值、配置上限、并发和熔断布尔值，不返回 API Key、原始 IP 或匿名设备 ID。管理员页面 `/admin/models` 可视化平台汇总；`/admin/users` 单独显示各轻量账号当日调用与 Token，不显示请求内容或供应商密钥。

生产环境建议单独注入高熵 `WORD2HTML_MODEL_USAGE_HASH_SECRET`。不要使用 `VITE_` 前缀，也不要写进前端文件。

## 当前边界与迁移

当前状态存于单个 Node 进程内存：服务重启后清零，不支持多个进程共享，也不提供财务级精确账单。多实例阶段应使用 Redis 原子脚本承接窗口计数、每日汇总、并发租约和带 TTL 的幂等结果，并为模型任务增加异常退出后的租约回收。

登录用户的账号额度目前同样保存在单个 Node 进程内存，服务重启后当日计数清零；账号目录本身使用原子 JSON 持久化，不会随重启消失。多实例阶段应同时把账号用量迁移到 Redis 或数据库原子计数。
