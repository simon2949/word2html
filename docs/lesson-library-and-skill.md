# 场景生成 Skill 与实验库

## 当前实现

Word2HTML 提供两条无需再次调用在线模型的复用路径：

1. 官方库：随应用版本发布，当前包含椭圆焦点距离和、二次函数顶点、正弦函数参数、自由落体和双单摆演示。
2. 第三方库：任何 LessonScene 0.1 或 `.word2html.json` 文件通过完整导入校验后，自动保存在当前浏览器中并标记为“待管理员审核”。

用户可以从任一库打开实验，随后使用相同的参数、显示、播放、缩放和 HTML 导出能力。相同场景指纹的重复导入会更新原条目，不会无限复制。

## Skill

项目 Skill 位于 `skills/word2html-scene-author`。它生成下面的紧凑信封：

```json
{
  "format": "word2html.lesson-package",
  "formatVersion": "0.1",
  "kind": "lesson-plan",
  "apiVersion": "lesson-plan-0.9",
  "plan": {}
}
```

采用 LessonPlan 而不是完整 LessonScene，可以减少输出 token，并把模板实例化、默认外观、对象生成和安全检查留给应用。Skill 包含能力矩阵、格式说明、代表性示例和确定性校验脚本。

## 信任边界

- “导入成功”只证明协议、表达式、数值和当前渲染器兼容，不证明知识点、单位、结论或教学方式正确。
- 外部文件不能声明自己是官方内容。导入器拒绝场景包信封中的额外审核字段。
- 当前第三方库位于浏览器 `localStorage`，不会静默上传，因此尚不存在跨用户共享或真正的管理员审核。
- 官方条目只能通过源码修改、自动测试和人工审查加入。
- 不执行模型生成的 HTML、JavaScript、URL 或第三方依赖。

## 共享第三方库的服务端阶段

后续接入共享目录服务时，建议使用以下状态流：

```text
本地导入成功
  → 用户明确同意提交
  → quarantined（隔离）
  → automated-passed（自动检查通过）
  → pending-review（待人工审核）
  → verified / rejected / deprecated
```

自动检查至少包括协议版本、文件大小、哈希去重、表达式安全、运行时资源上限、完整场景实例化、代表参数采样和 HTML 导出烟雾测试。人工检查至少包括学科正确性、K12 适龄性、单位和结论、可操作性、版权来源和恶意/误导内容。

服务端应保存不可变版本、SHA-256、提交者、审核人、审核时间和撤回原因。普通用户默认只搜索官方与 `verified` 内容；提交者可以在自己的库中使用待审核版本。被撤回或废弃的条目不能继续推荐，但已有本地副本应显示明确警告并允许安全导出。

## 官方内容晋升

稳定的第三方实验可以按以下流程晋升：

1. 管理员选择高复用且已验证的条目；
2. 固定表达式、参数范围、教学说明和能力指纹；
3. 增加学科不变量与边界测试；
4. 将条目加入官方源码目录；
5. 随应用版本发布，第三方旧版本标记为已被官方版本替代。
