# 共享第三方实验目录 MVP 验收

## 用户流程

1. 导入通过校验的 LessonScene 或 `.word2html.json` 后，条目只进入浏览器本地库并显示“本地未审核”。
2. 点击“提交共享审核”时出现明确确认，取消后不产生网络请求。
3. 确认后只上传紧凑 LessonPlan 场景包和可选原文件名，不上传完整外观、模型密钥或任意可执行代码。
4. 相同包重复提交返回同一个 SHA-256 条目，不重置已有审核状态。
5. 新哈希自动按 `third-party-ai-review-standard.md` 执行 AI 预审，并把结论、问题和建议附加到管理员队列。
6. AI 未发现问题、发现问题或调用失败都不能自动改变 `pending`；管理员必须最终决定。
7. `pending`、`needs-changes`、`rejected` 和 `deprecated` 条目不出现在普通用户的共享目录中。
8. 管理员设为 `verified` 后，其他用户刷新共享库即可打开；浏览器会重新进行完整导入校验。
9. 共享或模型服务不可用时，本地导入、编辑与导出仍可使用，并显示非破坏性错误。
10. 用户重新打开第三方实验库时，客户端用本地保存的精确场景包查询该版本的审核状态；不能枚举或下载其他待审核内容。
11. `needs-changes` 条目显示管理员意见和 AI 建议，按钮改为“打开并修改”，并把审核意见预填到左侧修改描述。
12. 用户修改后点击顶部“保存修改”，本地条目更新为新内容；随后可从实验库提交新审核版本，旧审核结论不会错误套用到新内容。
13. 管理员预审区和用户退回意见均提供大字号阅读弹窗，完整展示问题、位置和处理建议，并支持继续调节字号。
14. 用户保存退回场景的修改版时，本地条目记录原提交 ID；重新提交后服务端验证原版本状态和学科，并建立 `revisionOf` / `supersededBy` 版本关联。
15. 管理员打开修改版时直接看到原退回意见和 LessonPlan 确定性差异，可在原版本与修改版之间跳转；差异比较不调用AI。
16. 管理员可一键运行本地确定性检查，覆盖当前场景、参数边界、运行区间、不变量、控件与视口；结果可放大阅读且不消耗AI token。
17. 管理员审核页按时间倒序展示提交、版本关联、AI预审和每次人工决定；旧0.1目录可兼容读取，并在下一次操作时持久化历史。

## 管理与安全

- 管理员接口未配置 `WORD2HTML_ADMIN_TOKEN` 时返回 503，令牌错误时返回 401。
- 管理员令牌只从服务端进程环境读取，不进入 `VITE_` 变量、浏览器存储或导出文件。
- `/admin/reviews` 使用短期 HttpOnly、SameSite=Strict 会话；写操作必须携带只存在内存中的 CSRF token。生产 HTTPS 部署可以启用 Secure Cookie。
- 网页审核通过前必须运行确定性检查且不能存在失败项，并勾选科学内容、参数边界、视觉效果和主要交互四项人工检查；自动提醒项必须由管理员判断，退回修改与拒绝必须填写审核意见。
- 目录文件采用 0600 临时文件和原子重命名写入，默认目录已加入 `.gitignore`。
- 提交接口默认按连接地址限制为每 10 分钟 20 次，超限返回 429。
- 公共接口只返回 `verified`；本地 `localStorage` 伪造的 `verified` 会被降级为 `pending`。
- 提交者状态接口只接受完整且通过校验的精确场景包，并只返回状态、管理员反馈和预审建议，不返回目录中的场景包、内容哈希或 token 用量。
- 修改版本只允许关联处于 `needs-changes`、`rejected` 或 `deprecated` 的同学科原提交；无效、缺失或不符合状态的关联必须拒绝。
- 服务端再次检查场景包信封、当前 API 版本、LessonPlan Schema、模板一致性和表达式标识符。
- AI 预审工具输出必须通过 `LessonPreReview 0.1` Schema 和结论一致性检查；场景内容按不可信数据处理，不能覆盖系统审核标准。
- 审核事件历史仅由管理员接口返回；公共库和提交者状态接口均不得泄露内部事件、模型错误或历史审核意见。

## 自动验证

- 服务端目录测试覆盖隔离、审核后公开、退回修改、SHA-256 去重、过期协议拒绝、管理员令牌比较、追加式审核历史、旧目录兼容和历史数据隔离。
- 管理员会话测试覆盖 HttpOnly Cookie、过期、注销、Bearer 兼容和写操作 CSRF 防护。
- 客户端测试覆盖共享包二次校验、公共接口拒绝 pending，以及只提交紧凑包。
- 场景自动检查测试覆盖椭圆耦合边界、通用函数完整通过、仅在参数最大值触发的时间实验失败、控件缺失提醒和无效场景停止采样。
- 本地库测试覆盖伪造审核状态降级。
- `npm test`、`npm run build` 与 `git diff --check` 全部通过。
