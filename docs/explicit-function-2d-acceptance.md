# 二维显函数运行时：验收标准

文档版本：0.1

更新日期：2026-08-27

关联能力：`math.function.explicit-2d`

关联模板：`math.function.generic-2d@1`

状态：自动测试、正弦官方场景真实浏览器验收和 `word2html@0.1.0` 学科人工复核均已通过，平台注册状态为 `verified`。

## 1. 能力范围

运行时绘制单值显函数 `y=f(x)`，表达式只允许注册表规定的数学运算符、白名单函数、`x` 和最多 6 个数值参数。模型或导入文件只提供紧凑声明式规格，不提供 HTML、JavaScript、SVG 路径、采样点或网络资源。

当前官方代表场景为 `y = A sin(Bx)`，默认 `A=2、B=1`，用于验证振幅与频率参数的本地重采样。多分支关系、参数曲线与几何轨迹应路由到对应的关系曲线或参数轨迹运行时。

## 2. 必需验收项

### AC-F01 表达式与安全

- 拒绝未知标识符、属性访问、赋值、脚本、URL 和非有限范围；
- 定义域限制在 `[-50, 50]` 内且总跨度不超过 100；
- 参数 ID、范围、步长与当前值通过 Schema 和语义校验；
- 固定安全解析器完成求值，不使用 `eval` 或 `new Function`。

### AC-F02 数值与绘制

- 定义域内至少存在有限可绘制样本；
- 非有限点与跨度过大的跳变不会被错误连成连续线段；
- 参数修改后在浏览器本地重新采样，模型 token 为 0；
- x、y 使用同一像素比例，网格保持正方形，刻度不明显重叠。

### AC-F03 工作台交互

- 公式说明位于函数图像上方，图像铺满圆角框内容区；
- 参数、缩放、适应窗口、显示开关与对象级曲线样式可用；
- 参数和对象样式写入草稿，并支持撤销、重做和场景包导入导出；
- 参数设置与对象细调职责分离，不在整体显示设置中重复曲线线型控件。

### AC-F04 独立 HTML

- 导出文件在本地包含表达式解析、采样、参数控件、缩放和重置运行时；
- 场景对象 ID 和当前参数保持一致；
- 不包含 API Key、模型提示词、外部脚本、样式或网络请求。

## 3. 真实浏览器验收

执行命令：

```bash
npm run acceptance:explicit-function -- 9333 http://127.0.0.1:5173
```

若 `9333` 没有正在运行的 Chrome 调试端口，脚本会自动启动隔离的无头 Chrome；应用本身仍需通过 `npm run dev` 运行。

2026-08-27 的正弦官方场景执行记录已通过以下断言：

- 公式位于画布上方，SVG `viewBox` 为 `0 0 900 590`，画布铺满圆角框内容区；
- 横纵网格间距均约为 `42.60 px`；
- 默认指标显示 `A=2、B=1`，函数路径包含完整采样结果；
- 改为 `A=4、B=2` 后路径和参数指标同步更新，草稿保存当前值；
- 函数曲线对象级虚线与 `100%→110%` 缩放生效；
- 独立 HTML 含安全显函数运行时与 `functionCurve` 对象，未发现外部脚本或样式依赖。
