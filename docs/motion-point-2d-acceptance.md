# 二维质点运动统一验收

文档版本：0.1

更新日期：2026-08-27

关联能力：`physics.motion.point-2d`

关联运行时：`experiment.motion.point-2d@4`

状态：自动测试、历史用例、当前协议统一真实浏览器验收和 `word2html@0.1.0` 学科人工复核均已通过，平台注册状态为 `verified`。

## 1. 代表场景

统一验收顺序加载两个官方场景：

1. `official.free-fall`：覆盖单运动物体、持续时间、轨迹、当前高度和速度、速度矢量、恒定重力加速度矢量及到达终点自动停止；
2. `official.dual-pendulum`：覆盖两个独立运动物体、两条独立轨迹、两个绳约束、派生摆角、共享重力参数及两组独立摆长/初始角参数。

两者共用同一个安全时间实验运行时。模型或导入文件只能声明表达式、参数、测量量、物体、矢量和约束，不能提供逐帧数据、HTML、JavaScript 或网络资源。

## 2. 必需验收项

### AC-M01 单体运动与终点

- `h0=20、g=9.8` 时自由落体初始高度为 `20 m`、速度为 `0 m/s`；
- `t=0` 显示重力加速度矢量，不绘制长度为零的速度矢量；
- 播放后时间、高度、速度、物体位置、速度矢量和轨迹同步变化；
- 修改初始高度后回到 `t=0`，参数在本地重新计算并保存；
- 到达 `sqrt(2h0/g)` 后自动停止，高度为 0，速度与理论值一致。

### AC-M02 多物体与约束

- 双摆同时显示 `pendulum1`、`pendulum2` 两个摆球和 `rope1`、`rope2` 两条绳；
- 播放后两个摆球和两条轨迹均独立变化；
- 默认绳长标签分别为 `1.00 m` 和 `1.50 m`；
- 把 `L1` 改为 `2.2` 后，`L2` 仍为 `1.5`，时间回到 0；
- 在起点及运行区间中间点，两条绳的当前长度始终等于各自自然长度。

### AC-M03 显示、保存与导出

- 公式位于画布上方，画布铺满圆角框内容区，坐标网格保持正方形；
- 运动物体、轨迹、矢量和约束支持对象级点线样式；
- 缩放、参数草稿、播放/暂停与重置均在浏览器本地完成，AI token 为 0；
- 独立 HTML 包含相同的单体/多体、矢量、绳/弹簧、轨迹、参数和播放运行时；
- 导出文件不含 API Key、动态代码或网络依赖。

## 3. 执行命令

```bash
npm run acceptance:motion-point -- 9333 http://127.0.0.1:5173
```

应用需要先通过 `npm run dev` 运行。未检测到指定 Chrome 调试端口时，脚本会通过公共浏览器连接层自动启动隔离的无头 Chrome。

2026-08-27 已在隔离的无头 Chrome、`http://127.0.0.1:5181` 实际执行通过：自由落体在 `h0=32、g=9.8` 时于 `2.56 s` 自动停止，高度为 `0`、速度为 `25.04 m/s`；播放期间速度/重力矢量和轨迹同步显示。双摆同时显示两摆球、两轨迹与两条绳；把 `L1` 改为 `2.2 m` 后 `L2` 保持 `1.5 m`，起点和运行区间中间点的两条绳长误差均小于 `1e-8`。对象样式、缩放、草稿和无网络依赖独立 HTML 也全部通过。
