# 大模型规划自动纠错验收

接口版本：`lesson-plan-0.6`

## 目标

当 MiniMax 已理解教学目标，但 LessonPlan 存在字段、引用、表达式、数学或物理校验错误时，系统可自动反馈错误并纠错一次，不要求用户复制错误重新描述。

## 调用边界

- 模板命中、参数修改、显示修改和缓存命中仍为 0 次模型调用；
- 本地无歧义规范化能够修复时，模型只调用 1 次；
- 仍未通过校验时最多增加 1 次纠错调用；
- 第二次结果仍无效时立即停止并保留当前场景，绝不开始第三次调用；
- 两次调用的输入、缓存输入和输出 token 分别求和，界面显示实际调用次数。

## 纠错链路

1. 服务端校验失败：沿用第一次工具调用上下文，通过 `tool_result` 返回精确错误，再强制生成修正后的 LessonPlan。
2. 浏览器深层校验失败：把原始目标、上一版服务端已校验计划和最多 2400 字的本地错误发送到同源服务，只调用一次修正。
3. 修正计划重新经过 LessonPlan、表达式、对象引用、数值、物理不变量、LessonScene 和渲染能力校验。
4. 只有完整通过后才替换场景并缓存。

## 安全

- 纠错输入中的上一版计划必须先通过服务端 LessonPlan 校验；
- 错误反馈有长度上限，请求体继续受 128 KiB 限制；
- 模型仍只能返回强制工具 Schema，不得返回或执行 HTML、JavaScript、URL 或浏览器 API；
- `eval` 和函数构造器保持禁用。

## 自动化验收

- 首次有效规划：1 次调用，`repaired=false`；
- 首次未知标识符、第二次有效：2 次调用，合并 token，`repaired=true`；
- 两次均包含未知标识符：抛出最终错误且调用次数严格为 2；
- 服务端计划通过但绳长物理校验失败：浏览器请求一次纠错并合并 token；
- 服务端已经使用纠错后浏览器仍拒绝：不再发起第三次调用。

## 当前验证

- 全量 83 项测试通过，生产构建通过；
- 真实 MiniMax-M3 纠错请求收到“自由落体绳长不恒定”的本地错误后，移除了错误绳约束并保留原有自由落体参数、运动和高度测量；
- 真实纠错调用使用输入 3587、缓存输入 128、输出 464 token，返回 `modelCalls: 1`、`repaired: true`；在完整用户生成流程中会与首次调用统计相加。
